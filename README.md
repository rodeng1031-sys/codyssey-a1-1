## ✨ 기능 목록

* **프롬프트 추가 (`add_prompt`)**: 제목, 내용, 카테고리를 입력받아 신규 프롬프트를 등록합니다. 빈 값 입력 시 재입력을 유도하며 기본 즐겨찾기는 해제(`False`) 상태로 등록됩니다.


* **프롬프트 목록 (`show_list`)**: 저장된 모든 프롬프트의 인덱스, 카테고리, 제목, 즐겨찾기(`⭐`) 여부 및 총 개수를 번호 순으로 출력합니다.


* **카테고리별 조회 (`show_by_category`)**: 지정된 카테고리 중 하나를 선택하여 해당 카테고리에 속한 프롬프트 목록만 필터링해 확인합니다.


* **프롬프트 검색 (`search_prompt`)**: 검색어를 입력받아 제목(`title`) 또는 내용(`content`)에 키워드가 포함된 프롬프트를 검색하여 표시합니다.


* **프롬프트 상세 보기 (`show_detail`)**: 프롬프트 번호를 입력받아 구분선과 함께 제목, 카테고리, 즐겨찾기 여부, 전체 본문 내용을 출력합니다.


* **즐겨찾기 관리 (`manage_favorite`)**: 프롬프트 번호를 선택하여 즐겨찾기 상태를 토글(추가 또는 해제)합니다.


* **즐겨찾기 목록 (`show_favorites`)**: 즐겨찾기(`⭐`)로 등록된 프롬프트들만 모아서 조회합니다.


* **프로그램 종료**: 메뉴에서 `0`을 입력하면 안내 문구와 함께 안전하게 프로그램을 종료합니다.

## 📂 프롬프트 카테고리

프로그램에서 기본 제공 및 관리하는 카테고리 목록입니다.

* **텍스트 생성**: 블로그 글 작성 도우미 등 텍스트 콘텐츠 및 글쓰기 지원 프롬프트


* **이미지 생성**: 제품 썸네일, 그래픽 등 비주얼 생성 프롬프트


* **영상 생성**: 비디오 대본, 스토리보드 등 영상 제작용 프롬프트


* **페르소나**: IT 컨설턴트 등 특정 전문직이나 성격을 부여하는 역할극 프롬프트


* **자동화**: 업무 프로세스 및 스크립트 자동화 프롬프트


* **기타**: 기타 다목적 프롬프트


* **직접 입력**: 사용자가 원하는 새로운 카테고리를 직접 입력하여 추가 가능
